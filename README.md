# Proxon-AirConditioning-and-T300-BoilerBoost-PV-Control-in-Node-Red
Use free solar power for cooling and hot water: Node-RED flow that switches the cooling function of a Proxon heat pump (Modbus RTU) and the T300 Boiler Boost (Shelly via MQTT) based on PV power, battery SOC and outside temperature – with hysteresis, Pushover alerts and Dashboard 2.0.
